# Pym

Pym is an experimental web engine written in Python that integrates a WSGI-compatible server and a dynamic rendering system. It is inspired by the classic PHP model.

# Installation

```bash
git clone https://github.com/davidleonstr/pym.git
```

# Installation as library

```bash 
pip install git+https://github.com/davidleonstr/pym.git
```
